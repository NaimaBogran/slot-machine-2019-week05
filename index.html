Other Slot Machine

How to Use:

  1. You start off with 1000 button eyes
  2. You can bid either 5 or 50 buttons
  3. Each time you get 3 ghost children's eyes in a row you win!
  4. If you bid 5 buttons and win, you get 10x more buttons
  5. If you bid 50 buttons and win, you get 100x more buttons
