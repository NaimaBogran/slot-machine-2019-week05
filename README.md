# 🎰 Week05 Bootcamp2019 Project: Slot Machine

### Goal: Build a Simple Slot Machine

Build a simple slot machine with minimum 5 items per reel and 3 reels - user should be able to bet min or max and have their total update.

How It's Made:
Tech used: HTML, CSS, JavaScript

This project was super fun to make. I wanted it to reflect my personality and include something I'm interested in. The functionality wasn't as complicated as I thought it would be, but I had the luxury of working on this project with others who were able to push me in the right direction.
